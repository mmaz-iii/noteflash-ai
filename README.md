# ⚡ NoteFlash AI
Professional-grade web utility designed to convert study notes, textbook summaries, and PDFs into clean, native Anki flashcard decks (`.apkg` & `.txt`) instantly using Google Gemini.

## 🚀 Features
* **📄 Native PDF Processing:** Upload multi-page textbooks or lecture notes directly.
* **🤖 AI Extraction Engine:** Powered by Google Gemini (`google-genai`), featuring adjustable difficulty and style controls.
* **✏️ Interactive Card Editor:** Review and edit flashcard pairs in a live data grid before exporting.
* **📦 True `.apkg` Export:** Generates native Anki package files ready for instant desktop import.

## 🛠️ Tech Stack
* **Framework:** Streamlit (Python)
* **AI Core:** Google Gemini API (`google-genai`)
* **Anki Compiler:** `genanki`
